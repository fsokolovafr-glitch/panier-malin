# Panier Malin — «Продукты: бюджет и запасы»

Локальное веб-приложение на русском языке для учёта покупок, домашних запасов и продуктового бюджета. Требования находятся в [`requirements.md`](requirements.md), этапы и проверки — в [`PLAN.md`](PLAN.md).

## Как запустить на macOS

1. Установите [Python 3.9 или новее](https://www.python.org/downloads/), если его нет.
2. Дважды нажмите на файл `start.command` в папке проекта.
3. Приложение само откроется в браузере. Если этого не произошло, откройте <http://127.0.0.1:8000>.

При первом запуске нужен интернет для автоматической подготовки. Чтобы остановить приложение, вернитесь в окно запуска и нажмите `Control + C`.

## Что работает на этапе 2

- Пять адаптивных русских экранов: «Обзор», «Добавить», «Покупки», «Дома», «Купить».
- Ручной ввод покупки. Пустые цена, количество, магазин и дата не додумываются.
- Черновики, история, поиск, исправление суммы и исключение из личного бюджета.
- Необязательный месячный лимит. Без него показываются только фактические расходы.
- Постоянное SQLite-хранилище. Деньги хранятся в целых центах, а разные валюты считаются отдельно.
- Защита от повторной отправки одной и той же формы.

## Что проверено

12 автотестов пройдены на macOS с Python 3.9.6 и Flask 3.1.2. Подтверждены сохранность после перезапуска, точный расчёт бюджета, пересчёт после исправления, исключение из бюджета, неучёт черновика, защита от дубля, поиск, необязательный бюджет, отсутствие выдуманных значений, схема базы и открытие всех пяти экранов. Приложение также запущено через `start.command`; пять маршрутов ответили HTTP 200.

## Что ещё не готово

Домашние запасы, список «Купить», свободный текст, загрузка и OCR чеков, экспорт/восстановление и ручная приёмка на узком экране относятся к следующим этапам.

## Личные данные

База создаётся локально в `var/data/`. База, чеки, экспорты, `.env` и секреты исключены из Git. В репозитории нет реальных покупок.
