# Panier Malin — «Продукты: бюджет и запасы»

Panier Malin — локальное веб-приложение на русском языке для учёта покупок, домашних запасов и продуктового бюджета. Исходные требования находятся в [`requirements.md`](requirements.md), а план работ — в [`PLAN.md`](PLAN.md).

## Текущее состояние

Сейчас завершён только этап 1: архитектура, план и безопасные заготовки настроек. Функционального кода ещё нет, поэтому приложение пока нельзя запустить. Это не публичный сайт.

## Как будет устроено приложение

- Веб-интерфейс адаптируется к компьютеру и телефону.
- Python-сервер обрабатывает формы, правила бюджета, запасы и экспорт.
- SQLite хранит данные на компьютере, чтобы они не пропадали после закрытия браузера или перезапуска.
- Фото и PDF чеков хранятся отдельно от базы.
- Распознавание чеков изолировано в OCR-модуле. Без подключённого провайдера ручной ввод и остальное приложение должны работать.

Деньги будут храниться в целых минимальных единицах (например, в евроцентах), чтобы избежать ошибок двоичной арифметики. Суммы в разных валютах не складываются без явного правила пересчёта.

## Предлагаемая структура папок

```text
panier-malin/
├── app/                    # веб-приложение
│   ├── main.py             # точка запуска
│   ├── config.py           # настройки из окружения
│   ├── web/                # маршруты и формы
│   ├── templates/          # русские HTML-страницы
│   ├── static/             # CSS, иконки и небольшой JavaScript
│   ├── domain/             # правила покупок, бюджета и запасов
│   ├── storage/            # SQLite, репозитории и миграции
│   ├── services/           # сценарии приложения, экспорт и восстановление
│   └── ocr/                 # контракт OCR и адаптеры провайдеров
├── migrations/             # версии схемы базы
├── tests/                  # автотесты и приёмочные сценарии
├── scripts/                # запуск, экспорт и восстановление
├── var/                    # локальные данные; не попадают в Git
│   ├── data/                # база SQLite
│   ├── receipts/            # загруженные чеки
│   └── exports/             # экспорты и копии для восстановления
├── .env.example            # безопасный пример настроек
├── PLAN.md                 # этапы и критерии готовности
├── README.md               # понятная инструкция
└── requirements.md         # источник требований
```

Это целевая структура. На этапе 1 функциональные папки и файлы ещё не создаются.

## Запуск для нетехнического пользователя

Инструкция станет исполняемой после появления кода. Планируется такой порядок:

1. Установить Python 3.12 или новее.
2. Скачать проект и открыть его папку.
3. Скопировать `.env.example` в `.env`. Для обычного локального запуска ничего в нём не менять.
4. Запустить подготовленный сценарий для Windows, macOS или Linux.
5. Открыть в браузере адрес, который покажет сценарий запуска.

До реализации эти шаги служат целевым планом, а не подтверждённой инструкцией. В дальнейших этапах README будет обновлён по фактически проверенным командам.

## Личные данны

База, чеки, экспорты, локальные настройки и секреты не попадают в Git. В демонстрационных данных не будет реальных покупок.
